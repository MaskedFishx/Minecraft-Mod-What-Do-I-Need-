# Changelog

## 1.1.6
- HUD 鼠标交互收紧为仅游戏内 / 聊天框打开时可用（暂停界面、JEI、背包、容器等一律禁用拖拽与双击等）

## 1.1.5
- 打开背包/容器时禁用 HUD 鼠标交互（拖拽、双击、右键、滚轮调大小），点击可正常穿透操作背包，避免多列布局时的干扰；聊天框等非容器界面仍可交互

## 1.1.4
- 修复追踪较多配方换列后 HUD 不显示、出现透明空块的问题（移除过时的行数截断，所有配方按列完整渲染）

## 1.1.3
- 修复多配方时后添加条目显示为空/占位的问题（渲染异常隔离，单块出错不再影响其他行）；工作方块显示改为“× 工作方块 制造”且恢复正常字号

## 1.1.2
- 新增 ↑/↓ 键选择上/下一个配方（可自定义，原切换键保留）；HUD 配方行显示“物品名 × 工作方块”（灰色 × + 工作方块图标）；默认键调整：切换配方 Tab、数量界面鼠标中键（N/V 不变）

## 1.1.1
- 数量调整界面新增 1–256 滑动条，±按钮移到滑动条下方且不超过 256；JEI 兼容范围放宽至 19.21.0.247 及以上（公开 API 全部兼容，内部配方定位做了 19.21/19.39/19.4x 三套适配，个别旧版拿不到配方布局时自动降级为悬停物品反查，其余功能不受影响）

## 1.1.0
- 移除 ↑/↓ 切换合成方案功能（存在不稳定问题）；保留并沿用 JEI 配方界面按鼠标停留位置精确追踪

## 1.0.9
- 新增 ↑/↓ 切换选中配方的其他合成方案；修复 JEI 19.39（ATM10）下多配方界面按 G 追踪不准的问题（现在按鼠标停留的具体配方精确追踪）

## 1.0.8
- 模组更名为 **What Do I Need?（WDIN）**（modid、包名、语言键、存档路径等全部同步）；材料匹配升级为“智能识别 JEI 配方声明的接收物品/标签”（具体物品只认物品，声明了标签的才按标签匹配），修复 1.0.7 过于严格 / 旧版过宽的问题

## 1.0.7
- 材料匹配改为严格按 JEI 配方物品（Tag 合并关闭），修复 ATM10 中几乎所有物品被误识别/误高亮的问题

## 1.0.6
- 兼容 JEI 19.39.x（ATM10 整合包自带版本），依赖范围放宽为 19.39.0.368 及以上

## 1.0.5
- HUD 自动换列（双击配置菜单新增“单列配方数”1–4）

## 1.0.4
- 数量调整界面居中重排；N 键描述更新；双击 HUD 配置菜单；悬停滚轮调大小；G 单击切换、长按 G+滚轮上下切换

## 1.0.3
- HUD 配方选择功能（V 移除选中、H 数量界面、右键选中）

## 1.0.1
- 未追踪配方时 HUD 完全隐藏

## 1.0.0
- 初始版本（RCPTracker）
