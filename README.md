# What Do I Need?（WDIN）

基于 NeoForge 21.1（Minecraft 1.21.1）的纯客户端材料追踪模组，**硬依赖 JEI**。核心功能对标 “JEI 配方标记 + 缺料清单显示”。

## 功能

- 在 JEI 配方界面 / 背包 / 容器界面按下 **Tab**，把光标下的配方加入追踪列表（新追踪的配方会自动选中）；JEI 同屏展示多个配方时，按鼠标停留的**具体配方**精确追踪
- HUD 配方行显示对应工作方块：`物品名 × 工作方块 制造`（× 为灰色，工作方块图标+名字为正常字号）
- 材料匹配**智能识别 JEI 配方声明的接收物品/标签**：配方是具体物品就只认该物品；配方接收某个标签（如“任意木板”）才按该标签合并计数，配方限定之外的物品不会被误判
- 可配置是否忽略 NBT 差异（默认忽略）
- 在 JEI 物品列表或背包悬停物品按 **N**，追踪该物品本身 / 取消追踪
- 未打开任何界面（或打开背包/容器但光标下没有物品）时，**单击 Tab** 顺序切换选中的追踪配方；**按住 Tab + 鼠标滚轮** 上下切换
- **↑ / ↓** 直接选择上一个 / 下一个追踪配方（可自定义）
- 按 **V** 移除当前选中的追踪配方
- 按 **H**（可自定义）打开选中配方的数量调整界面：**滑动条（1–256）**快速设置数量，下方保留 **-10 / -1 / +1 / +10** 按钮（按钮调整同样限制在 1–256 内）与移除 / 关闭
- HUD 的鼠标交互（右键选中、左键拖拽、双击配置菜单、悬停滚轮调大小）仅在**游戏内**或**聊天框打开**时可用；暂停界面、JEI、背包、容器等其余一切界面均禁用，不会干扰正常操作
- HUD 上**双击**打开 HUD 配置菜单：透明度、大小、单列配方数（1–4）
- 单列配方数满后自动换列，新列显示在右侧，第一列位置不变（默认 10）
- 鼠标悬停在 HUD 上时，**滚轮直接调节 HUD 大小**（透明度只在配置菜单里调）
- 自动扫描主背包、快捷栏、副手以及打开的箱子/木桶等容器内的物品（每 200ms 节流）
- 容器中所需材料会被高亮（绿色=足够，红色=不足）
- 未追踪任何配方时 HUD 完全隐藏
- 追踪列表持久化到 `.minecraft/wdin/tracked.json`，重启不丢失

## 按键

| 按键 | 功能 | 可改 |
| --- | --- | --- |
| Tab | 无物品选中时单击切换选中配方；界面内光标下有物品时追踪该物品 | 是 |
| N | 追踪该物品本身 / 取消追踪（光标下的物品） | 是 |
| V | 移除当前选中的追踪配方 | 是 |
| 鼠标中键 | 打开选中配方的数量调整界面 | 是 |
| ↑ / ↓ | 选择上一个 / 下一个追踪配方 | 是 |
| 滚轮 | 按住 G 时上下切换选中配方；悬停 HUD 时调整 HUD 大小 | - |
| 双击 | 在 HUD 上双击打开 HUD 配置菜单（透明度/大小/单列配方数） | - |

按键可在 `设置 -> 控制 -> What Do I Need?` 中修改。

## 配置

- `config/wdin-client.toml`：HUD 样式、扫描规则、颜色等（NeoForge 标准配置）
- `.minecraft/wdin/hud.json`：HUD 位置/大小/透明度/单列配方数（拖拽或菜单调整后自动保存）
- `.minecraft/wdin/tracked.json`：追踪列表数据

## 安装

1. 需要 Minecraft **1.21.1** + NeoForge **21.1.238 及以上** + JEI **19.21.0.247 及以上**（强制依赖 JEI，缺失将无法启动；兼容 19.21.0.247 往上的主流版本，包括 ATM10 的 19.39.x）
2. 将 `wdin-1.1.6.jar` 放入 `.minecraft/mods/`
3. 启动游戏

## 从源码构建

- 需要 JDK 21
- 克隆仓库后执行：Windows `gradlew.bat build`，macOS/Linux `./gradlew build`
- 构建产物位于 `build/libs/wdin-1.1.6.jar`
